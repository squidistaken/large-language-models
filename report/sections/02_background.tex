\section{Background}
\label{sec:background}

\subsection{Multi-label Emotion Classification}
\label{sec:background_multilabel}

XED \parencite{ohman2020xed} uses Plutchik's eight basic emotions: anger, anticipation, disgust, fear, joy, sadness, surprise, and trust. Since a subtitle line can carry several of these emotions, a model has to make eight separate yes or no decisions rather than select one emotion class. We will therefore score each prediction as a set, mainly with micro-averaged F1 and per-line Jaccard similarity, because predictions are rarely all correct or all wrong, which plain accuracy does not capture. Emotions are also unevenly spread, so rare ones leave little to learn from.

\subsection{XED, Label Projection and Cross-Lingual Transfer}
\label{sec:background_xed}

XED is a dataset of movie subtitles from OpenSubtitles, in which each line comes without the dialogue surrounding it. Only the English and Finnish lines were annotated by people. Labels for thirty additional languages, including Croatian, were obtained by annotation projection, and we will treat them as projected reference labels rather than human judgements. In annotation projection, the subtitles of the same film in two languages are aligned, mainly by their timing, and the emotions of a line are copied to its aligned line. A projected label may therefore be inaccurate, because aligned lines are not necessarily translations of each other, or because the translation changed the emotion of the original line.

Cross-lingual transfer means training in one language and testing in another. We will test it by evaluating an English-only fine-tuned model on Croatian, and a bilingual condition will show whether adding Croatian training data helps beyond that.

\subsection{Parameter-Efficient Fine-Tuning}
\label{sec:background_peft}

Updating every weight of a model with billions of parameters is costly, since training also keeps a gradient and optimiser state for each of them. Parameter-efficient fine-tuning (PEFT) avoids this by freezing the pretrained model and training only a small number of added parameters. We will compare two such methods. Low-Rank Adaptation (LoRA; \cite{hu2022lora}) gives each frozen weight matrix an update formed by multiplying two small trained matrices, called an adapter, which together take up a fraction of a percent of the model's parameters. QLoRA \parencite{dettmers2023qlora} additionally stores the frozen model in a 4-bit format, cutting the memory taken by its weights roughly fourfold at the cost of some rounding error.

\subsection{Prompting}
\label{sec:background_prompting}

Instruction-tuned language models are trained to respond to a request described in their input, the prompt. In zero-shot prompting, the prompt holds only the instruction; in few-shot prompting, it also contains a handful of solved examples (demonstrations), from which a model can infer the task without changes to its weights \parencite{brown2020language}. Prompting needs no training, but its results can be fragile, so we will analyse prompt sensitivity on the development set. Few-shot performance changes with the wording of the prompt and with which demonstrations are shown, partly because models favour labels that are frequent among the demonstrations \parencite{zhao2021calibrate}.
