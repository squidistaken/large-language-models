\section{Data and Task Setup}
\label{sec:data}

\subsection{XED for English and Croatian}
We used the English and Croatian portions of XED \parencite{ohman2020xed}. Each example is a single subtitle line from a film, without the surrounding dialogue, labelled with one or more of Plutchik's eight basic emotions: anger, anticipation, disgust, fear, joy, sadness, surprise and trust. We kept these eight labels, in this order, from data preparation through to evaluation. XED distributes its neutral lines separately and they are not part of the task, so every line in our data carries at least one emotion.

Croatian has no human annotations in XED. Its labels were projected from human-annotated subtitles onto aligned Croatian lines, so we treat them as projected reference labels, not as judgements of the Croatian text itself (Section~\ref{sec:background_projection}). To build matched pairs, we linked every Croatian line to an English line through XED's subtitle alignments. Of the 5,422 pairs left after cleaning, 2,236 are aligned directly (one hop). For the other 3,186, XED links the Croatian line only to a Danish subtitle, and we reached the English line through Danish (two hops). Where a Croatian line had several English counterparts, we preferred one with a human annotation, then the one with the fewest hops.

The English side carries XED's human labels wherever they exist, which is the case for 5,247 pairs (96.8\%). The other 175 English lines have no human annotation and take the projected labels of their Croatian counterpart. Since the two languages' labels come from different files, they can differ within a pair, as for the second demonstration in Table~\ref{tab:demonstrations}. For every line, we recorded the number of alignment hops and the source of its labels; Section~\ref{sec:analysis} uses these to separate model errors from alignment and projection errors.

Figure~\ref{fig:label-distribution} shows how often each emotion occurs. The two languages are almost identical, as nearly all labels share one origin. Anger and anticipation are the most frequent, each on about a quarter of the lines, and disgust is the rarest, on about one line in eight. A Croatian line carries 1.45 emotions on average.

\subsection{Split and Leakage Controls}
XED's Croatian file has 5,941 labelled lines once three malformed rows are removed. Of these, one could not be aligned to any English subtitle. Tokenisation and punctuation differ between the XED files we join, so we compared lines after normalising Unicode, case, punctuation and spacing. Under this comparison, 518 further lines repeat a Croatian line already in the data, and we kept only the first occurrence of each. This is stricter than exact matching: lines that differ only in punctuation, such as an exclamation and a question, also count as repeats. The result is 5,422 English--Croatian pairs, in which no Croatian line occurs twice. English lines can still repeat, because different Croatian lines are sometimes aligned with the same English text: 612 English lines occur in more than one pair. We grouped the pairs that share an English line and assigned each group to a single partition, so no line, in either language, appears in more than one partition.

We then made one fixed 70/20/10 split into training, development and test sets, with seed 42. Pairs were assigned by their XED alignment identifier before the English and Croatian files were written, so both versions of a subtitle share a partition, and the English data holds exactly the English counterparts of the Croatian lines. To keep each emotion's share similar across partitions, we used iterative multi-label stratification \parencite{sechidis2011stratification, szymanski2017network}, as implemented in the \texttt{iterstrat} package: the training set was split off first, and the remaining 30\% was divided 2:1 into development and test sets. Stratification used the Croatian labels, merged over the pairs in each group. This gave 3,803 training, 1,068 development and 551 test lines per language. Each emotion's share differs by at most 2.3 percentage points between the Croatian partitions, and by at most 2.7 between the English ones, which were not stratified directly (Table~\ref{tab:split-support}, Appendix~\ref{app:split}).

All design decisions, including prompt, hyperparameter and checkpoint selection, were made on the development set, and the test set was used only for the final evaluation. The five-shot demonstrations were drawn from the training set only.

\subsection{Data Formatting}
\label{sec:data_formatting}

Every pair was written out in a conversational format, separately for each language and partition. An example has three messages. The system message holds the task instruction: it lists the eight permitted labels in the fixed order, each with a one-line definition, states that every line expresses at least one of them and may express several, and asks for a JSON list of the matching label names and nothing else. The user message holds the subtitle, as \texttt{Subtitle: \{text\}}, and the assistant message holds the reference labels as a JSON list of English label names in the fixed order, for example \texttt{["anger", "fear"]}. Croatian examples use the same English instruction and English label names, and only the subtitle changes, so the output format, parser and metrics are the same for both languages. The full wording is in Appendix~\ref{app:prompts}.

The same files serve both adaptation approaches. In fine-tuning, the model is trained to produce the assistant message from the system and user messages. In prompting, the model receives the system and user messages and generates the answer itself; the five-shot prompt inserts five demonstrations as user and assistant turns between the two. Zero-shot prompting and the fine-tuned models therefore see the same input. Each example keeps its alignment identifier, and a manifest written with the split records a hash of the instruction together with the seed and split settings.
