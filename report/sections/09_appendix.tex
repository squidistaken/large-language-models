\section{Code Repository}
\label{app:repository}

The code is available at \href{https://github.com/squidistaken/large-language-models}{https://github.com/squidistaken/large-language-models}, on the \texttt{main} branch. The version submitted with this report is published as a release on the repository's \href{https://github.com/squidistaken/large-language-models/releases}{releases page}. Each fine-tuned adapter has a model card in the \texttt{model\_cards/} folder, describing its base model, training data, prompt template, settings and the commands to reproduce it. The adapter weights themselves are not published.

\section{Prompts}
\label{app:prompts}
\raggedbottom % keep the prompt boxes together instead of stretching the space between them
\tcbset{before skip=10pt, after skip=10pt} % a fixed gap between the prompt boxes

Every prompt has a system message and a user message. The system message is one of the instruction templates below, in which \texttt{\{definitions\}} is replaced by the label definitions; the user message holds the subtitle. In the five-shot prompts, the demonstrations (Table~\ref{tab:demonstrations}) are inserted as user and assistant turns between the two.

\begin{tcolorbox}[title={Label definitions, replacing \texttt{\{definitions\}}}]
\begin{verbatim}
- anger: displeasure or hostility at a perceived wrong
- anticipation: expecting or looking forward to something
- disgust: revulsion or strong disapproval
- fear: feeling threatened or afraid
- joy: happiness or pleasure
- sadness: sorrow, loss or disappointment
- surprise: reaction to something unexpected
- trust: confidence in, or acceptance of, someone or something
\end{verbatim}
\end{tcolorbox}

\begin{tcolorbox}[title={User message}]
\begin{verbatim}
Subtitle: {text}
\end{verbatim}
\end{tcolorbox}

\begin{tcolorbox}[title={Template \texttt{default} (used on test)}]
\begin{verbatim}
You classify the emotions expressed in a movie subtitle line.

Permitted labels:
{definitions}

Every line expresses at least one of these emotions and may express
several. Answer with a JSON list of the matching label names, using
only the names above, and nothing else, in the format ["label", ...].
\end{verbatim}
\end{tcolorbox}

\begin{tcolorbox}[title={Template \texttt{terse} (dev only)}]
\begin{verbatim}
Label the emotions in this subtitle line. Choose one or more of:
{definitions}

Reply with only a JSON list of the chosen label names, like ["label",
...].
\end{verbatim}
\end{tcolorbox}

\begin{tcolorbox}[title={Template \texttt{annotator} (dev only)}]
\begin{verbatim}
You are an expert annotator of emotions in film dialogue, using
Plutchik's eight basic emotions:
{definitions}

Read the subtitle line and decide which of these emotions it
expresses; a line can express one emotion or several at once. Respond
with a JSON list of the label names exactly as written above, and no
other text.
\end{verbatim}
\end{tcolorbox}
